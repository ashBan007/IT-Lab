# Lab 02: OSI Troubleshooting

## Objective
Troubleshoot network issues layer by layer using the OSI model.

## Issues Solved

### Issue 1: Physical Layer
- Disabled network adapter
- Result: ping failed
- Solution: Enabled adapter

### Issue 2: Application Layer
- Changed to wrong DNS server
- Result: nslookup failed
- Solution: Set correct DNS

## What I Learned
- Troubleshooting from bottom to top
- Physical → Network → Application
- Each layer has specific checks
